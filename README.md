# LOOI Workmate · web

Landing page de **LOOI Workmate**, el compañero de mesa que convierte el robot LOOI en un asistente en español: mira tus calendarios de Google y Outlook y te cuenta el día en voz alta.

Publicada con GitHub Pages: https://twinlab-experiments.github.io/looi-workmate-site/

Este repositorio solo contiene la web publicada. La fuente es `site/index.html` en el repositorio principal del proyecto, y los cambios se hacen allí y se copian aquí.

Proyecto independiente construido sobre el robot LOOI. No está afiliado a su fabricante.
